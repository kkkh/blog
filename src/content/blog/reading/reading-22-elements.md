## 一、为什么读它

学生时代，几何等于背定理加画辅助线。我从没把它当一本书读，只当一堆必须记住的结论。那些结论为什么成立、凭什么成立，老师不讲，我也不问。

后来起了一个念头：一本被当作教科书用了两千年、又被当成「真理」典范的书，究竟靠什么站住？抱着这个念头翻进去，撞见两个意外。

一个是开头。它列在卷首的，不是五条不言自明的真理，而是五条请你先**答应**的请求。另一个是第一条命题：作一个等边三角形，几步就做完，可我盯着图看了半天，才看出它偷偷用掉了一个谁也没写明的假设。

## 二、先看骨架

:::info
《几何原本》共十三卷，约四百六十五条命题（通行本通常作 465 条），成书于公元前三百年左右，是亚历山大里亚时期几何知识的一次大整理。第一卷开头列出 23 条定义、5 条公设、5 条公理（又称「共同概念」）。它全程不用代数符号，凡涉及数量运算，都用线段和图形来做——所以书里常有「拿图形代替公式」的段落，读起来像在动手，而不是在计算。
:::

十三卷的分工，我先列成一张表：

| 卷 | 内容 |
| :--- | :--- |
| 一 | 定义、公设、公理；三角形与平行线的基本命题，含勾股定理 |
| 二 | 用几何方式处理代数恒等式，即所谓「几何代数」 |
| 三—四 | 圆的性质，以及内接、外接多边形 |
| 五—六 | 比例论与相似形 |
| 七—九 | 数论：整除、比例，以及素数无穷 |
| 十 | 不可通约量的分类 |
| 十一—十二 | 立体几何，以及用「穷竭法」处理体积 |
| 十三 | 构作五种正多面体，全书以此收束 |

+++primary 展开：我读时最在意的几条命题（我的私人批注）
- **I.1**：作等边三角形。全书的第一个证明，只有寥寥几步
- **I.5**：等腰三角形底角相等。中世纪有个绰号叫「驴桥」，相传是学几何的第一道坎
- **I.47**：勾股定理。它的图形俗称「新娘椅」，也叫「风车」
- **V**：比例论。用「量」而不是「数」来处理比例，技术上最难
- **IX.20**：素数有无穷多个。全书最出名的纯数论命题
- **XIII**：五种正多面体的构作，全书收尾处
+++

一个提醒：「公设」和「公理」在中文里常被合起来说，其实本来分得很清。五条公设谈的是图形世界的操作——作线、作圆、相交；五条公理谈的是关于「相等」的普遍规矩。分清这一点，往后读每一卷才知道它默认了什么。

## 三、摘录与旁注

### 关于起点：第一条就是一句请求

> 设：由任意一点到任意一点，可以作一条直线。
>
> ——第一卷，公设一[^3]

==它被排在全书最前面，措辞却是一个「设」——不是在陈述事实，是在请求你答应。==欧几里得把地基修成了一份协议：这些事，请你先点头，后面的讨论才谈得下去。

我的旁注：这一步其实很现代。一切严谨的推理，都得先把「前提从哪里来」交代清楚。他不假装前提是从天上掉下来的，只把它摊在桌上，问你认不认。

### 关于最不像公设的那条公设

> 若一条直线落在两条直线上，使同旁内角之和小于两直角，则这两条直线无限延长后，必在那一侧相交。
>
> ——第一卷，公设五

++着重点++{.dot}前四条公设都短得像常识：两点连线、线段可延长、可作圆、直角都相等。==唯独第五条又长又绕，怎么看都不像「显然」。==两千多年里，无数人想把它从其余几条里推出来，直到十九世纪才有人掉过头来承认：它不是必然，只是众多选择之一。

我的旁注：这条被嫌别扭的公设，后来长出整片非欧几何。最不起眼的一条假设，反而成了最有出息的一条。

### 关于第一个证明：一个没说出口的假设

> 在一条给定的有限直线上，作一个等边三角形。
>
> ——第一卷，命题一

==这是全书的第一次证明，短得几乎看不见。==以线段两端为圆心作两个圆，取它们的交点，连起来，三角形就成了。

:::success
**藏在图里的那一步**

欧几里得的作法是取两个圆的交点。可翻遍五条公设，没有一条保证「两个圆一定相交」——它默认了这件事，只是没写出来。两千多年后，希尔伯特重排几何公理时，专门补上了一批这类被默认的前提。这不算挑错，而是看清一件事：最讲究的书，也会在显而易见的地方留一个缺口[^1]。
:::

我的旁注：读到这里我才明白，所谓「严谨」，不是没有漏洞，是把漏洞摆到一个你迟早会撞见的位置上。

### 关于全书最有名的一条

> 在直角三角形中，直角所对边上的正方形，等于两直角边上正方形之和。
>
> ——第一卷，命题四十七

[笔记]{.label .primary}==换成今天的写法，就是 $a^2+b^2=c^2$。==但欧几里得不用字母，他画三个正方形，用割补说明大正方形怎么拼成两个小的。同一个事实，一边是符号，一边是图形，他选了后者。

我的旁注：这个图在中世纪被叫作「新娘椅」，也有人说像风车。名字越叫越花，道理其实只有一句：换一种摆法，面积守恒。

### 关于意料之外的一卷

> 素数的个数，比任何指定的素数个数都要多。
>
> ——第九卷，命题二十

++着重点++{.dot}==一本从头到尾讲图形与线段的书，忽然给出这样一条纯数论的断言。==证明干净得惊人：任取一组素数，把它们乘起来再加一，所得的数要么本身是素数，要么能被一个不在这组里的素数整除——无论如何，列表之外总有素数。

我的旁注：这一卷最能说明这本书的气质。它讲的不是某条结论有多惊人，而是「证明」这件事本身可以走到多远。

:::warning
**读它之前：两件小事**

一个是版本。中译本里，「公设」「公理」「定义」的译法并不统一，同一处有的译「公设」有的译「假设」，读着容易串。挑本子时，先翻到第一卷开头，看它怎么排列表头那三条，大致就知道这本的脾气。另一个是方法。它不用符号，一切靠作图与割补，所以旁边最好放纸笔——照着画一遍，比对着文字读一遍快得多[^2]。
:::

## 四、心得与用法

1. **读证明，先追「它用了前面哪几条」。** 每一条命题都建在已证的结论上。读完一条，随手记下它引用了哪些命题号，一两卷下来，全书的依赖关系会显出一张网——你就明白它为什么非要从公设开始不可。
2. **手边放纸笔，照着作图。** 这本书是为双手写的。两个圆、一条割线、几个正方形，画出来和只在脑子里想，完全是两回事。凡读到「作某某」，就停下来画。
3. **把公设当「谈好的前提」，不当「真理」。** 一旦这么读，「第五公设能不能改」就不再是废话，而是天然会冒出来的问题——后来真有人改了，也真长出一片新几何。

## 五、落笔

合上书，我改掉了一个偏见：原以为这样的书没有「作者」，只有结论。读完才知道，它更像一位工匠的现场记录——先跟你把前提谈好，再一步步把整座建筑砌起来，砌到最后一卷，还留了一手，用五种正多面体给自己收尾。

下一本准备读《奥德赛》：一本要你一步一步跟着证明的书读完了，下一本要你一步一步跟着漂流。一个把「确定」讲到极致，一个把「意外」讲成人生；我想看看，这两种「一步一步」到底差在哪里。

[^1]: 这个缺口留了很久：从欧几里得到希尔伯特，中间隔了两千两百多年。希尔伯特在 1899 年重写几何公理时，补上了一批被默认而未言明的前提，其中就包括圆与圆的相交。这个例子常被用来说明：所谓「显然」，往往只是「没被追问过」。
[^2]: 关于「公设」与「公理」的译名：欧几里得原文里，前五条是 αἰτήματα，字面意思是「所求之事」，故有人译「公设」；后几条是 κοιναὶ ἔννοιαι，意为「共同观念」，故有人译「公理」。译名不同，读者对「哪一条是请求、哪一条是共识」的感受也跟着不同。

[^3]: 本篇中文引文是内容转写（自译）：欧几里得原文为古希腊语，各家译文用词不一，我不假托任何译本的原句，只把命题的意思转写清楚。
