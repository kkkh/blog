## 一、为什么读它

第一次读《百年孤独》是在大学图书馆，读了三章就被人名劝退——「何塞·阿尔卡蒂奥」和「奥雷里亚诺」来回出现，我照着书后的人物表画家族树，画到第三代就绷不住了。那本还了回去。

第二次是冬天。一个下午，我翻到开头三页——「多年以后，面对行刑队，奥雷里亚诺·布恩迪亚上校将会回想起……」——被这句话的时态卡住，来回读了两遍，然后一口气读完了。

读完才明白，那些重复的名字不是门槛，是线索。马尔克斯没有偷懒：同一个名字配同一类脾气，同一种脾气引向同一类下场。读者被绕晕，恰恰因为他把「被困住」这件事写进了命名规则里。

## 二、先看骨架

:::info
《百年孤独》1967 年出版，是加西亚·马尔克斯最广为人知的小说，全书二十章，不分部。写的是马孔多这个小镇，和布恩迪亚家族七代人一百年的兴衰。中文首部授权译本由范晔翻译，2011 年出版；在此之前，市面上的中译本大多未获授权。
:::

第一次读总被人名拖住，是因为缺一张「名字地图」。我把七代人的名字与结局理成一列：

| 代 | 反复出现的名字 | 结局 |
| :--- | :--- | :--- |
| 第一代 | 何塞·阿尔卡蒂奥、乌尔苏拉 | 建起马孔多；晚年被绑在栗树下 |
| 第二代 | 奥雷里亚诺（上校）、何塞·阿尔卡蒂奥、阿玛兰妲 | 上校打三十二场仗；兄妹彼此错过一生 |
| 第三代 | 阿尔卡蒂奥、奥雷里亚诺·何塞 | 一个死在行刑队枪下，一个死于非命 |
| 第四代 | 俏姑娘蕾梅黛丝、孪生的奥雷里亚诺第二与何塞·阿尔卡蒂奥第二 | 一个升天，两个把家业玩坏 |
| 第五代 | 何塞·阿尔卡蒂奥、梅梅、阿玛兰妲·乌尔苏拉 | 出走、私情，又回到马孔多 |
| 第六代 | 奥雷里亚诺·巴比伦 | 与姑母相爱，破译羊皮卷 |
| 第七代 | 长着猪尾巴的孩子 | 被蚂蚁吃掉，全书收束 |

+++primary 展开：名字里的两条性格线（我的私人批注）
- **叫何塞·阿尔卡蒂奥的**：冲动、强壮、爱走大路；一生往外闯，也一生撞墙
- **叫奥雷里亚诺的**：孤僻、固执、爱钻一样东西——战争、金币、羊皮卷；他们的孤独是往里塌的
- **叫阿玛兰妲的**：往往和「爱而不得」绑在一起，蜜糖里带着毒
- **乌尔苏拉**：唯一清醒的人，活过一百多岁，看着全家重复每一轮错误
- **蕾梅黛丝**：两次出现，两次都不属于这个世界——一个早夭，一个升天
+++

一个提醒：别把「孤独」读成一个抒情词。在马尔克斯手里，它是一个机制：一个人一旦只按自己的方式活，就必然把祖辈的路再走一遍。名字的重复，是这套机制的开关。

## 三、摘录与旁注

### 关于「开场」：全书第一句就把时间搅乱了

> 多年以后，面对行刑队，奥雷里亚诺·布恩迪亚上校将会回想起父亲带他去见识冰块的那个遥远的下午。
>
> ——第一章

==这一句把三个时间焊在了一起：==当下（面对行刑队）、未来（多年以后）、过去（去见识冰块的那个下午）。读完这句，你已经被卷进马孔多那种「时间绕圈」的感觉里。

[笔记]{.label .primary}「冰块」是全书反复回收的信物。最开始它是父亲的探险，后来它是上校童年的证据，最后它成了马孔多失落的旧物之一。**一个意象反复出现**，是这部小说真正的针脚。

### 关于「命名」：世界太新，东西还没有名字

> 世界新生伊始，许多事物还没有名字，提到的时候需要用手指指点点。
>
> ——第一章

[危险]{.label .danger}==一句看似浪漫的话，其实是全书的写作纲领。==东西没名字，就得指着说；等名字有了，人们反而忘了自己指的是什么。

++着重点++{.dot}书里有段著名的「失眠症」：全镇人先睡不着，接着开始遗忘，于是给每一样东西贴上标签——「这是桌子」「这是牛」。**名字一旦流失，连日常起居都无从下手**。这段其实在替全书解释：为什么布恩迪亚家的名字要反复用。名字是抵抗遗忘的锚。

### 关于「孤独」：一封只有五个字的电报

> 「马孔多在下雨。」
>
> ——赫里内勒多给奥雷里亚诺上校的电报
>
> 「八月下雨很正常。」
>
> ——上校的回电

==一封想求安慰的电报，被一句天气挡了回去。==赫里内勒多想要的是「我也想念你」，收到的是气象报告。

[笔记]{.label .primary}这是全书讲「孤独」讲得最省力的一次：两个人关系再近，也听不懂对方在说什么。上校一辈子打三十二场仗，把人越打越少，话也越说越短。到后来他不是不想说，是真的不会说了。

### 关于「结局」：羊皮卷与最后一句话

> 羊皮卷上所载的一切自永远至永远不可重复，因为注定经受百年孤独的家族不会有第二次机会在大地上出现。
>
> ——全书最后一章

==全书收尾这句，也是马尔克斯给整部小说留的题词。==它把「重复」与「终结」同时扣上：马孔多的历史只会发生一次，布恩迪亚家也只有这一代。

[笔记]{.label .primary}读到最后一页才明白：前面七代人的重复，是为了让这最后一句成立。**如果一切只能发生一次，那么重复本身就是这本书替孤独做的实验**。

:::success
**「魔幻现实主义」这个标签，贴得准不准**

两派吵了很久。一派说这是一部政治寓言：香蕉公司的大屠杀、打不完的内战、被风卷走的镇子，桩桩都指向拉丁美洲的历史；另一派说，那些最离奇的事——升天、飞毯、长猪尾巴的孩子——在他的叙述里被讲得像家史一样平静，说明魔幻只是家族记忆的讲述方式。我的读法是：两层都成立，但别把「魔幻」当卖点，那种把奇迹讲成家常的平静，才是他的本事。
:::

:::warning
**一个译本上的坑**

《百年孤独》在中国的译本史很特别。2011 年之前，市面上的中译几乎都未经授权，多据英文或西班牙文转译，甚至有不少删改；2011 年南海出版公司拿到授权，请范晔重译，才有了「正本」。所以你在旧书摊上读到的那本，可能根本不知道转了几道手。就算都是正规译本，人名也差得远——奥雷里亚诺／奥雷良诺，蕾梅黛丝／雷梅苔丝，乌尔苏拉／乌苏拉。选译本时，先看它的人名前后是否统一，再看它有没有把家族关系讲清楚。
:::

## 四、真正用上的三条读法

1. **自己画一张家族树，分两栏写。** 左栏全是「何塞·阿尔卡蒂奥」，右栏全是「奥雷里亚诺」。画完你会发现，书名里那两个人的命运，早就写在两栏的对照里。
2. **把「又发生了一次」当提示音。** 每读到一件事「又发生了一次」，停一下，回头找上一次。重复不是作者啰嗦，是这本书的语法。
3. **记住名字的性格规律，而不是记住人名。** 你不必背下七代人的全名，只要记住：叫何塞·阿尔卡蒂奥的往外冲，叫奥雷里亚诺的往里缩。抓住这条规律，人名就从障碍变成了路标。

## 五、落笔

读完《百年孤独》，我最大的收获不是「魔幻」两个字，而是对「重复」的耐心。以前我觉得人生最怕的是推翻重来；现在有点理解马尔克斯：比推翻重来更可怕的，是一遍遍走回老路却毫无察觉。

下一本准备读《理想国》：同样是一群人建一座城、定一套规矩，一个把城建在雨林的想象里，一个把城建在辩论里。我想看看，哪一种城更经得起追问。

[^1]: 马孔多有现实原型：马尔克斯出生在哥伦比亚小镇阿拉卡塔卡，他外祖父母的宅子就是小说里那所大房子的底本；「香蕉公司」对应的是 1928 年当地人罢工被镇压的真实事件。他后来说过，不是他写出了魔幻，是拉丁美洲的生活本身就长这样。
