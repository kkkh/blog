## 一、为什么读它

很多年里，我对《孙子兵法》的印象，是一本「计谋手册」：培训课上被反复引用的成功学，商战书里被拆成一条条锦囊的书。真翻开原文才发现，它比这些用法安静得多，也严肃得多。

第一句就把我按住了。它不谈计谋，先谈分量：兵者，国之大事。一本书的开头若把话题定在「死生之地」，后面的话就没法轻飘。

读下去，更意外的是它的重心。最有名的一本兵书，通篇在劝你尽量别打：能不打就不打，非打不可也要速战。它把「不打」列为上策——这跟印象里的兵书，几乎是反的。

## 二、先看骨架

:::info
《孙子兵法》共十三篇，约六千字（通行本约六千余字），旧题春秋末年孙武所著。篇幅不长，语气却极克制，几乎没有故事，全靠断语。1972 年山东临沂银雀山汉墓出土了一批竹简，其中就有《孙子兵法》，与传世本互有异同——这也是今人重新校读它的一个起点。
:::

十三篇的次序，本身就像一条作战的流程。我列成一张表：

| 篇 | 内容 |
| :--- | :--- |
| 始计 | 五事七计；开篇「兵者，国之大事」 |
| 作战 | 战争的成本；「兵贵胜，不贵久」 |
| 谋攻 | 「不战而屈人之兵」「知己知彼」 |
| 军形 | 先使自己不可战胜，再等敌人可被战胜 |
| 兵势 | 势与节；「以正合，以奇胜」 |
| 虚实 | 致人而不致于人；避实击虚 |
| 军争 | 争利与迂直；「以迂为直」 |
| 九变 | 各种地形与「君命有所不受」 |
| 行军 | 处军相敌，观察敌情 |
| 地形 | 六种地形；「知彼知己，胜乃不殆」 |
| 九地 | 九种处境；「投之亡地然后存」 |
| 火攻 | 火攻的条件，以及慎战 |
| 用间 | 五种间谍；全书收尾 |

+++primary 展开：我读时记下的几句关键话（我的私人批注）
- **始计**：「兵者，国之大事，死生之地，存亡之道，不可不察也」
- **谋攻**：「不战而屈人之兵，善之善者也」
- **军形**：「先为不可胜，以待敌之可胜」
- **兵势**：「凡战者，以正合，以奇胜」
- **虚实**：「致人而不致于人」
- **九地**：「投之亡地然后存，陷之死地然后生」
+++

一个提醒：别把它当「厚黑学」读。它谈的是成本与胜算——先算出打不打得赢、耗不耗得起，再谈怎么打。把它读成整人技巧，正好反了它的本意。

## 三、摘录与旁注

### 关于「分量」：全书的第一句

> 兵者，国之大事，死生之地，存亡之道，不可不察也。
>
> ——《始计篇》

==开篇不谈诡计，先谈分量。==「不可不察」四个字，把整本书的调子定住了：这是一件要反复掂量的事，不是一件可以逞快的事。

[笔记]{.label .primary}后来被引滥的「兵者，诡道也」也在这篇里，但它紧跟在「不可不察」之后。先教你别轻率，再教你战时怎么迷惑对方——次序一颠倒，就成了另一本书。

### 关于「上策」：一条反常识的主张

> 是故百战百胜，非善之善者也；不战而屈人之兵，善之善者也。
>
> ——《谋攻篇》

++着重点++{.dot}==百战百胜，在它这里不算最好；不用打就让对方服气，才算最好。==一本兵书把「不打」抬到最高处，这是它最不像兵书的地方。

我的旁注：这句话常被当成道德高调，其实它非常务实。百战百胜意味着打了上百次，上百次都要死人、耗粮；能让对方不战而降，省下的正是这些。它赞美的不是仁慈，是效率。

### 关于「判断」：一句人人会说的老话

> 知彼知己，百战不殆。
>
> ——《谋攻篇》

==这八个字被说得太熟，读原文反而容易滑过去。==它强调的顺序是「知彼」在前、「知己」在后——最难的是看透对方，最容易被忽略的是看透自己。

[危险]{.label .danger}==注意它说的不是「百战百胜」，是「不殆」——不败。==目标从「赢」降到「不输」，这是全书一贯的谨慎：先把失败的门关死，再谈胜负。而且这里只到「不殆」；若还要「必胜」，就得再「知天知地」。

### 关于「不败」：主动权从哪里来

> 昔之善战者，先为不可胜，以待敌之可胜。不可胜在己，可胜在敌。
>
> ——《军形篇》

++着重点++{.dot}==能让自己不被战胜的，是自己；能不能战胜对方，却要看对方。==于是它把力气全花在前一件上：先把自家的漏洞补上，再等对方露出破口。

我的旁注：这句话解释了它为什么反复讲「守」。守不是消极，是把不可控的部分交给时间，把可控的部分牢牢攥住。等，也是一种动作。

### 关于收尾：以间谍作结

> 故惟明君贤将，能以上智为间者，必成大功。
>
> ——《用间篇》，全书最后一篇

==一本讲打仗的书，最后落在「情报」上。==它把用间说得很重：肯花大价钱买消息，才是省钱的打法；舍不得这笔钱的，常常赔掉整场战争。

[笔记]{.label .primary}收在这里并不突兀。前面讲了成本、胜算、地势、火攻，最后回到最根本的一件：你对敌人的了解，值多少。它宁可在开战前把钱花在消息上，也不愿在战场上花在尸体上。

:::success
**十三篇为什么这样排序**

从前到后，它其实在走一条链：先算该不该打（始计、作战），再想办法少打（谋攻），再谈怎么立于不败（军形），然后才轮到怎么打（兵势、虚实、军争），接着是各种具体处境（九变、行军、地形、九地、火攻），用情报收尾。一场仗的次序，被它安排成了一次可以复盘的决定流程[^1]。
:::

:::warning
**读它之前：两件小事**

一是版本。今人常读的，有宋本《十一家注孙子》一路，也有《武经七书》一路；1972 年银雀山汉墓竹简出土后，通行本与古本之间的异文又被重新讨论过一遍。挑本子时，看它有没有交代底本出处。二是读法。它几乎全是断语，没有故事，读快了像格言集；慢读一遍，把每句放回它所在的篇里，才知道它在回答什么问题[^2]。
:::

## 四、心得与用法

1. **先算成本，再谈胜负。** 「兵贵胜，不贵久」不是鼓励速战，是提醒「拖」本身就是亏。换个场景也一样：把「赢」和「耗得起」分开算，很多不必要的仗会当场取消。
2. **先为不可胜。** 动手前先问一句：万一不成，我最坏失去什么，这个我守得住吗。守得住，再谈下一步。它把「不败」当成自己能掌控的部分，是很实用的一条。
3. **致人而不致于人。** 尽量让对方跟着你的节奏走，而不是你被事情拖着跑。哪怕只是一场谈话，先想清楚「今天谁定节奏」，结果就会不同。

## 五、落笔

二十四篇读到这里，正好收尾。回头看第一篇《论语》，才发现两本书在同一个点上握了手：它们都不谈运气，只谈判断——一个教你看清一个人，一个教你看清一个局势；一句是「己所不欲，勿施于人」，一句是「知彼知己」。说到底是同一件事：动手之前，先看清对面是谁。

这一系列从《论语》走到《孙子兵法》，二十四种读法各不相同，合起来却是同一种习惯：把书当成一次可以反复回到现场的练习。写到这儿，可以合上了。

[^1]: 关于次序：十三篇的排列未必出自孙武一人之手，后世整理者可能也参与了编定；但就现成的次序读，它确实像一条从「要不要打」到「怎么打」的决策链。
[^2]: 关于「兵者，诡道也」：这句出自《始计篇》列举「诡道」诸法之处，谈的是战场上的示形与迷惑。它是书中的一小节，不是全书的主旨；全书的主张更接近「先胜而后求战」。
