## 一、为什么读它

第一次翻开《伊利亚特》是冲着木马去的。翻到第二卷就卡住了：那是一份船名录，几十行里全是部落、将领和船数，情节一动不动。我合上书，心想这大概是留给研究者看的。

真正把我拽回去的，是一个后来才知道的结构事实：特洛伊战争打了十年，这部诗只取最后一年里的五十来天。它不急着讲完一场战争，只切下一小段，用慢镜头看。

读完才发现，这一小段里最有分量的东西，都不是战争本身。第一行点明的不是战事，是「愤怒」；最有名的英雄阿喀琉斯，大半时间待在帐篷里罢战；而全诗的末行，落在一场葬礼上。

## 二、先看骨架

:::info
《伊利亚特》是荷马史诗之一，分二十四卷，通行本约一万五千七百行（常见计数为 15693 行），用六音步长短短格写成。故事发生在特洛伊战争第十年，前后只跨约五十天。它不从头交代起因：海伦被拐、联军远征，这些都不讲——诗人假定你早已知道，直接从一个「争吵」写起。
:::

读不下去的人，多半是名字没接住。我给自己配了一张卷次表：

| 卷次 | 讲什么 |
| :--- | :--- |
| 一 | 争吵：阿伽门农夺走布里塞伊斯，阿喀琉斯罢战 |
| 二 | 阿伽门农试探军心，以及那份著名的船名录 |
| 三—四 | 帕里斯与墨涅拉俄斯单挑，休战随即破裂 |
| 五—七 | 狄俄墨得斯逞威，赫克托尔与埃阿斯互换礼物 |
| 八—十 | 特洛伊占了上风，夜探敌营 |
| 十一—十五 | 阿伽门农负伤，战局倒向特洛伊 |
| 十六 | 帕特罗克洛斯披挂阿喀琉斯的铠甲出战，死于赫克托尔 |
| 十七—十九 | 为一具尸体而战；阿喀琉斯得新盾，与阿伽门农和解 |
| 二十—二十二 | 阿喀琉斯复出复仇，杀死赫克托尔，拖尸绕城 |
| 二十三 | 为帕特罗克洛斯举行葬礼竞技 |
| 二十四 | 老王普里阿摩斯夜入敌营赎回儿子的尸体，全诗收尾 |

+++primary 展开：两支军队，几张脸（我的私人批注）
- **希腊一方**：阿伽门农，联军统帅，先前的错多在他身上；阿喀琉斯，最强的战士，也是最会记仇的人；帕特罗克洛斯，阿喀琉斯的朋友，第十六卷里最重的一场死；奥德修斯，「多智」的代表，谈判与夜袭都靠他；埃阿斯，力气最大的那一类人
- **特洛伊一方**：赫克托尔，守城的支柱，全诗真正的主角之一；普里阿摩斯，老王，最后一卷才登场；帕里斯，引祸的人，善射而不善战；安德洛玛刻，赫克托尔的妻子，第六卷里最动人的声音
- **不定的一方**：众神。他们各有偏爱，甚至下场干预——读的时候得记住，站在哪一边的，不只是人
+++

一个提醒：别在这本书里找「战争的道理」。它写的不是观点，是代价：愤怒怎么先伤到自己人，英雄气概怎么和残忍长在同一棵树上。

## 三、摘录与旁注

### 关于「愤怒」：全诗的第一个词

> 女神啊，请歌唱佩琉斯之子阿喀琉斯的愤怒，那毁灭性的愤怒，给阿开亚人带来了无尽的苦难……
>
> ——第一卷，开篇[^2]

==全诗第一句，唱的不是战争，也不是英雄，是一个人的「愤怒」。==后来的情节几乎都能追到这句上：他生谁的气、气多久、气消之后又做了什么。

[笔记]{.label .primary}有个细节耐琢磨：诗人求的不是「讲完这场战争」，而是「唱这个愤怒」。一首只写一段怒火的诗，反倒成了整个西方战争文学的源头。

### 关于「家」：赫克托尔回城的那一段

> 赫克托尔回城，与妻子安德洛玛刻告别。安德洛玛刻抱着幼子流泪，劝他别再上前线；他答，若像懦夫一样躲开战斗，他无颜面对特洛伊人。他伸手去抱孩子，孩子却被头盔上的马鬃吓哭，夫妻俩都笑了。他向神祈祷：愿这孩子日后比我更强，愿人们说「他比他的父亲好得多」。（大意）
>
> ——第六卷，赫克托尔与安德洛玛刻

++着重点++{.dot}这是全诗最安静的一段，也是它下手最重的地方。==写这段的诗人，先让最大的「敌人」在战斗之外做了一个父亲。==读者一旦见过赫克托尔的家，第二十二卷里他被拖尸的场景，才真正扎人。

我的旁注：史诗写到这儿，已经不再分敌我。诗人给了特洛伊人一个厨房、一张摇篮，也顺手递来一个立场：很难再痛快地为任何一方叫好。

### 关于「战」：萨尔佩冬对战友说的话

> 萨尔佩冬对格劳科斯说：朋友，如果我们能躲过这场战争、永远不死，我就不必冲在最前面；但既然死亡的关口时时在近旁，我们只能向前——要么把荣耀给别人，要么从别人那里赢来荣耀。（大意）
>
> ——第十二卷，萨尔佩冬对格劳科斯

[危险]{.label .danger}==这是全诗最像「战争伦理学」的一段，也是最诚实的一段。==它没给战争一个正义的理由，只给了一个事实：既然人都要死，便用「荣耀」去补上死亡留下的缺口。

我的旁注：这段话口气像在劝人勇敢，骨子里是一句坦白——找不到理由，只能拿名声顶上。

### 关于「原则」：阿喀琉斯拒绝使者

> 我痛恨那样的人，像痛恨冥府的大门一样：心里藏着一样，嘴上却说另一样。
>
> ——第九卷，阿喀琉斯的答复

==这一句让阿喀琉斯从一个闹脾气的战士，变成了一个有原则的人。==阿伽门农派人送来厚礼求和，他拒了。他说的不是「价钱不够」，是——礼物补得回损失，补不回送礼的人。

我的旁注：他在这里第一次显出自己会死。他提到母亲告诉过他：若守着不走，能得长寿却默默无闻；若为荣誉而战，命就短。他偏选了后者。这条原则，正是他后来放声大哭的原因。

### 关于「交还」：结尾的相见

> 特洛伊老王普里阿摩斯夜里潜入敌营，跪到杀死他儿子的阿喀琉斯面前，抱住他的膝，亲吻那双杀过他儿子的手。阿喀琉斯想起自己的父亲，两个人一同落泪。（大意）
>
> ——第二十四卷，普里阿摩斯与阿喀琉斯

==全诗最著名的场景，不在战场，在一顶帐篷里。==刚才还在拖尸泄愤的胜利者，此刻和敌人的父亲相对而哭。

:::success
**为什么一场葬礼可以作结**

全诗并不以胜利收场。阿喀琉斯和普里阿摩斯之间那段短暂的休战，不是靠道理谈成的，是靠两个同时想起了「自己会失去什么」的人。休战只有十二天，城终将陷落——诗人偏偏按下不表，让最后一个画面停在焚烧的柴堆旁。末行写的是：他们就这样为驯马的赫克托尔举行了葬礼。
:::

:::warning
**读它之前，先说清版本与名字**

中文译本主要有罗念生与陈中梅两家。前者多用音译、句式庄重，念出来好听；后者注释更密，适合第一次读的人对照。两本的人名译法不同，混着读容易乱。英文译本更多，人名有希腊式（Achilleus、Hektor）与拉丁式（Achilles、Hector）两路，正文里我用了更通行的一路。挑译本时，可以翻到第二十四卷，看它怎么处理那双「被亲吻的手」——这一段译得好不好，大致能看出全书的水准[^1]。
:::

## 四、心得与用法

1. **先搭「五十天」的时间轴，再认人。** 开头那份船名录不必硬啃。先把二十四卷按卷次过一遍，知道每一卷大致在哪一段事件里，再回头补名字，比起头就被名字淹掉省力得多。
2. **史诗要出声读。** 六音步长句在默读里几乎不成形。哪怕读的是中译，也可以按译本标出的停顿念出来；念到「驯马的赫克托尔」「足智多谋的奥德修斯」这样的固定形容语时，句子的断点会自己浮上来。
3. **阿喀琉斯发怒时，盯住代价落在谁身上。** 他的怒火先烧的是自己人：联军因此连番落败，帕特罗克洛斯因此赴死。盯着这个，才不会把这部诗读成一本英雄赞歌。

## 五、落笔

合上书，我改掉了一个偏见：原以为史诗就是战争的宣传片。它恰恰不替胜利者说话，它把镜头放在死者、生者和两边都在失去的人身上。一部两千七八百年前的诗，敢让胜利者哭着收场，这件事本身就够分量。

下一本准备读《几何原本》：一本讲战争的书，收尾是一场葬礼；一本讲图形的书，要从几条定义一步步往下推。一个把代价写进诗里，一个把证明写进格子里，我想看看「确定」这件事，读起来是什么滋味。

[^1]: 关于「荷马问题」：这两部史诗是否出自一人之手，学界争论已久。「分解派」认为它们由多人、多时代拼合而成；「统一派」主张有一个统摄全篇的诗人。读的时候不必先站队，先读到诗本身。
[^2]: 本篇引文多作「大意」或自译：荷马原文是古希腊语六音步诗行，各家译文出入不小，我没有把握还原某位译者的原句，所以只转写内容，不假托任何译本。
