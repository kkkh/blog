## 一、为什么读它

读完《伊利亚特》，隔了几个月才翻开《奥德赛》。原以为它是「神话冒险集」：独眼巨人、塞壬、女妖，货架上摆满了怪物。第一页就发现想错了。

更意外的是前四卷。主角压根没出场，尽是些坐着等的人：被求婚者占着家宅的妻子，出门找父亲的儿子。一部以英雄命名的诗，先讲了四卷别人的等待。

真正让我服气的是它的开篇。上一本《伊利亚特》的第一个词是「愤怒」，一上来就是火气；《奥德赛》的第一个词，唱的是一个「绕了很多弯」的人。同样是史诗，一个写人怎么发火，一个写人怎么回家。

## 二、先看骨架

:::info
《奥德赛》也是二十四卷，通行本约一万二千行（常见计数为 12109 行），与《伊利亚特》同用六音步格。情节当下的时间跨度不长，却把主人公十年漂泊的旧事嵌了进来：前半部在找他，后半部在讲他。它和《伊利亚特》最大的分别，是后者写战争与荣誉，它写回家与忍耐。
:::

二十四卷的走向，我列成一张表：

| 卷 | 内容 |
| :--- | :--- |
| 一—四 | 「帖雷马科纪」：家中的困局，儿子出海寻父 |
| 五—八 | 奥德修斯离开卡吕普索，漂到费埃克斯人处；听人唱他，落泪 |
| 九—十二 | 他自述十年漂流：独眼巨人、魔女喀耳刻、冥府、塞壬 |
| 十三—十六 | 回到伊塔卡，乔装乞丐，与牧猪人、儿子相认 |
| 十七—二十 | 在王宫中受辱，试探妻子与仆人 |
| 二十一—二十二 | 拉弓比试，射杀求婚者 |
| 二十三—二十四 | 与佩涅洛佩相认；次日似有和解，全诗收束 |

+++primary 展开：几张脸（我的私人批注）
- **奥德修斯**：多智、能忍，也极能编；整部诗有一半是他自己在讲自己
- **佩涅洛佩**：留守的妻子，用「白天织、夜里拆」的法子拖了求婚者许多年
- **帖雷马科**：儿子，前四卷真正的主角，从一个受气的少年长成能并肩的帮手
- **雅典娜**：一路相帮的神，替他改换外貌、出主意
- **路上的对手**：独眼巨人、喀耳刻、塞壬、卡吕普索——既是障碍，也像护照上的签章
- **欧迈俄斯**：牧猪人，全诗最「正常」的人，忠心的仆人也身兼向导
+++

一个提醒：别把它当冒险故事集读。怪物再多，也只是路标；这部诗的骨架是「回家」，每个插曲都在问同一个问题——离家的距离还剩多少。

## 三、摘录与旁注

### 关于开篇：第一个词是「人」

> 请告诉我，缪斯，那个绕了许多弯的人，他在荡平特洛伊圣城之后，漂泊了很远很远……
>
> ——第一卷，开篇[^3]

==上一本史诗的第一个词是「愤怒」，这一本唱的是一个「人」。==同一个「多弯」的词，既说他一路绕来绕去，也说他心里拐弯多——这条路是脚下的，也是心上的。

[笔记]{.label .primary}一个字的偏心很说明问题：写战争时，诗人先想到火气；写回家时，他先想到一个活人。两本书的分别，从第一行就摆在台面上了。

### 关于「伙伴」：一句话交代了失去

> 那些愚人，竟吃了太阳神赫利俄斯的牛，于是神剥去了他们回家的日子。
>
> ——第一卷，诗人插叙

++着重点++{.dot}==全诗的悲剧，一句话就交代完了：回家的日子是被自己弄丢的。==不是海妖，不是巨人，是没忍住嘴。这条「自我克制」的线，比任何一场风浪都要紧。

我的旁注：这样一来，剩下的旅程就有了另一层意思。他要克服的不只是海上的东西，还有自己那群「饿起来什么都吃」的同伴——而他最后是一个人回去的。

### 关于「无人」：一个救命的谎言

> 我的名字叫「无人」。
>
> ——第九卷，奥德修斯对独眼巨人

==他靠一个假「名字」活了下来。==独眼巨人被刺瞎后向同伴呼救，喊的是「『无人』在害我」，同伴便以为他疯了，没人来救。

[危险]{.label .danger}==这部诗第一次让「说谎」成了英雄的本事。==在《伊利亚特》里，强大靠力气；到了这里，活命靠嘴巴。同一个文化，两套标准，诗人把它们都写成了本事。

### 关于「拒绝」：卡吕普索的不死

> 女神答应让他长生不老、永不衰老，可她说服不了他的心；他仍日夜盼着回家，哪怕只能望见一缕炊烟。
>
> ——第五卷，奥德修斯在卡吕普索的岛上

++着重点++{.dot}==诱惑他的不是怪物，是一个「什么都给你」的好地方。==长生、安逸、美貌，一样不缺；他还是想走。整部诗里最强的一次对抗，对手不是恶，是好。

我的旁注：写这一节时，诗人没有把卡吕普索写成反派。她真心待他，也确实留不住他。这让「回家」两个字，从地理问题变成了价值选择。

### 关于「相认」：一张床的秘密

> 佩涅洛佩试探他，命人把婚床搬出去；他脱口道：床是我亲手做的，其中一根床柱，是长在地里的活橄榄树，谁也搬不动。这一句，才是真正的身份证明。
>
> ——第二十三卷，夫妻相认

==全书最动人的相认，靠的不是胎记或信物，是只有两个人才知道的私事。==二十年过去，容貌可以作假，这张谁也搬不动的床不会。

我的旁注：整部诗用了好几层辨认——狗认得主人，伤疤认得旧识，只有这棵树认得婚姻。诗人把最深的证据，放在一件家具上。

:::success
**三次辨认，一次比一次深**

老狗阿耳戈斯先认出他，摇尾而亡；乳母看到腿上的伤疤，认出他；妻子要等他亲口说出床的秘密，才肯认。三次辨认一次比一次靠近心口，也一次比一次难。所谓「回家」，不是推开一扇门，是让一个几乎被当作陌生人的自己，重新走进他原来的位置[^1]。
:::

:::warning
**读它之前：两件小事**

一是版本。中文译本里，人名与神名的译法差别很大，奥德修斯有时译「俄底修斯」，佩涅洛佩有时译「珀涅罗珀」，混读容易乱。挑本子时先看它译得顺不顺，再决定要不要备两手。二是读法。前四卷没有主角，容易读丢；不妨先把这几卷当成「家里的故事」单读，等主角第五卷登场，你再回去看他不在时是谁在扛着[^2]。
:::

## 四、心得与用法

1. **把「家」当成坐标，而不把冒险当地图。** 每读完一段路程，问一句：他离伊塔卡是更近还是更远。这么读，杂乱的插曲就串成一条线。
2. **读奥德修斯的自述时，盯住他在对谁说话。** 第九到十二卷整个是他的独白，听众是费埃克斯人。他是在编一套让自己体面的说法——讲故事的人，也在塑造自己。
3. **留意「招待」这条暗线。** 好客的人得分，坏客的主人出事，独眼巨人正是反面的主人。希腊人把「怎么待客人」看得极重，这条暗线比怪物更能看出人间。

## 五、落笔

合上书，我改掉了一个偏见：原以为它是本冒险故事集。它其实是本「回家」的书，而且告诉你，回家靠的不只是力气，还有忍耐、机智，和一个别人愿意相信的故事。最勇的一刻，不在杀巨人，而在那张谁也搬不动的床上。

下一本准备读《孙子兵法》：一本讲怎么回家的书写完了，下一本讲怎么「不打就赢」。奥德修斯把机智用在路上，《孙子兵法》要把机智用在避开战场；我想看看，同一种聪明，换一个用途会变成什么样。

[^1]: 关于「三次辨认」：狗、伤疤、床，分别对应旁观者、家人与伴侣。有论者认为，这一层层收紧的辨认结构，是全诗「回家」主题最精巧的设计——认得越快，回家越浅；认得越慢，位置越稳。
[^2]: 关于结构：主角在前四卷缺席，是先立起「家」和「等着的人」。另有学者主张「帖雷马科纪」未必是原诗所有；不论真相如何，按现成的次序读，仍是最省力的读法。

[^3]: 本篇中文引文是内容转写（自译）：荷马原文为古希腊语六音步诗行，各家译文出入不小，我不假托任何译本的原句，只转写内容与出处。
